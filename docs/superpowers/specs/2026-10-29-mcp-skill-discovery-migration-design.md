## 范围

1. MCP 保留结果信封并投影文本、结构化数据、有效图片和资源引用；错误在模型、实时与历史中保持一致。普通工具无默认短超时，初始化/发现/关闭仍有界；取消、共享初始化、配置/凭证变化和断流恢复按来源最终修正迁入。已发送操作不自动重放，取消或丢失响应不能冒称回滚成功。
2. Skills 设置新增已安装/发现标签，搜索声明公开目录或检查公开 GitHub 链接。预览完整选定包、固定 commit 和来源元数据，检查格式与声明依赖但不执行技能。用户明确点安装后才发布到现有授权本地根，冲突不覆盖、项目符号链接边界受限，来源可离线读取；远程安装和自动升级不在本版。
