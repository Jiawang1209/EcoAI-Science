# 未配置启动进入四步向导

用户确认所指的是首次使用配置向导，而不是底部状态栏；修复后验证通过再合并本地 main，不推送。

启动时等待模型目录与凭证结果，读取阶段显示具体的读取状态，不能把尚未返回的空名单解释为没有 agent。两份数据到齐且未配置、没有主动跳过时，在同一次渲染中进入现有四步向导；保存 Key 后仍保留向导，直到完成或主动跳过。已配置用户直接进入正常首页。

去掉侧栏重复的旧 agent 配置提示。主动跳过且确实没有模型时，主区保留明确的连接模型入口，重新打开完整向导；底部入口共用该导航动作，收起覆盖主区的终端/设置并离开当前会话视图，不删除会话。沿用原有持久化的主动跳过标记，不强制重置用户已有偏好，不更改凭证或连接配置。

验证：App 真实组件的延迟回复覆盖目录先返回、凭证先返回、全未返回和已配置情况；旧实现四例均失败。真实 Electron 验证从启动到四步向导不插入旧空态，跳过/重开正常；复验现有向导保存、跳过、重启、双语与解释器流程，以及类型检查、构建、全量 UI。通过后提交并快进合并本地 main，再更新用户当前打开的主程序界面。
