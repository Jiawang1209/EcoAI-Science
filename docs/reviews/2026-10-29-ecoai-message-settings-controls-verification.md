# EcoAI-Science：消息铅笔与设置勾选控件微调验收

日期：2026-10-29。按用户两张截图的要求，在独立分支 `codex/message-icons-settings-toggles` 修改，基线 main `781f61e8`。

## 改动

- 消息修改入口增加独立的铅笔描边变体，复用复制的 16×16 / 1.5px 圆端、圆角、currentColor 外壳。默认透明度同为 0.55，悬停/键盘聚焦恢复 1，保留原焦点环和 32px 按钮点击区域。其他重命名等位置的原实心铅笔不变。
- 整页设置原生 checkbox 从 22px 缩为 16px；实机发现侧栏容器不同，原先走 UA 的 13px，现同时限定 `.settings-body` 和 `.settings-column`，统一为 16px。相关 at-toggle 标签保持至少 24px 高，文字仍可点击，Space 切换、禁用语义、原生聚焦和主题色沿用原控件。聊天/文件选择区的 checkbox 不在本次样式作用域中。
- 不修改配置接口、存储、发送/复制/编辑行为、版本号、发布工作流或已接受的复制图标。

## 验证与复核

新增真实 Electron 判据先在旧构建上失败：铅笔的 fill/stroke/透明度与复制不一致，且设置 checkbox 实测为 22px。首版完成后整页通过，进一步改为实际点击侧栏后发现 13px，补齐两种容器后通过；没有将断言改成接受旧尺寸。

最终相关 UI 回归 5 文件、156 项通过（设计契约、通知设置、设置表单/切换及 i18n）；类型与完整构建通过。最终真实 Electron 5 文件、24 项全部通过，覆盖：

- 复制/消息修改的默认颜色、透明度、SVG 填充/描边/线宽和按钮尺寸一致；键盘聚焦可见，修改后取消保留原文，既有发送修改与复制反馈正常。
- 紧凑设置栏勾选框 16×16、标签高度至少 24、垂直居中误差最多 1px；点击标签切换，再由键盘 Space 切换。
- 展开到整页、切换暗色与 900×640 窄窗后仍为 16px、可见且无水平溢出；所有设置分类默认栏宽、侧滑和减少动态效果回归通过。
- 既有消息时间戳/操作行对齐、窄气泡不被动作行撑宽、消息历史及统计回归通过。未放宽 1px 几何阈值，也未更新既有逐像素视觉基线。

已人工查看完整和紧凑、亮暗截图及同时显示消息与设置的预览，未见新增裁切或错位。独立只读复核两轮无实证 P1/P2；补齐侧栏选择器后再次确认范围未波及设置外控件。
